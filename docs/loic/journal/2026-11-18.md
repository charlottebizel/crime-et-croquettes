## Problèmes et solutions

- **Commit « agentkit » fait directement sur `main`, puis `git pull` qui ouvre Vim pour un message de merge** : le kit avait été copié et commité sans créer de branche. Solution : sortir de Vim avec `:q!`, sauvegarder le commit dans une branche, `git reset --hard origin/main`, puis recommiter le kit sur `docs/agentkit`. Pour éviter Vim : `git config --global core.editor "code --wait"`.
- **Fichier parasite nommé `git` à la racine** : créé par une commande mal tapée. Solution : le supprimer, ne jamais le commiter.

- **La variable `messages` de la spec entrait en collision avec les notifications Django** : `base.html` affiche `messages` en haut de chaque page, la conversation y serait apparue. Solution : renommée `echanges` dans la spec et dans le code.
