{% comment %} ===================================================================== templates/composants/chat.html — Portrait d'un chat dessiné en SVG ===================================================================== Dessine la tête d'un chat (suspect ou inspecteur) à partir de son « apparence », telle qu'elle est stockée en base dans Suspect.apparence (voir docs/specification.md §3.2). Utilisation : {% include "composants/chat.html" with apparence=suspect.apparence label=suspect.nom %} {% include "composants/chat.html" with accessoire="inspecteur" label="Inspecteur Moustache" %} Paramètres : apparence (dict, optionnel) : { "pelage": "#RRGGBB", "rayures": "#RRGGBB", "rayures_opacite": 0 à 1, "yeux": "#RRGGBB", "museau": "#RRGGBB", "accessoire": "..." } accessoire (texte, optionnel) : force l'accessoire, sinon on prend apparence.accessoire. Valeurs : couronne, serviette, pelote, monocle, bandana, inspecteur, aucun. label (texte) : description lue par les lecteurs d'écran. Sans apparence, ce sont les couleurs de l'Inspecteur Moustache. Le SVG remplit son conteneur : c'est le parent qui fixe la taille. Sécurité : les couleurs viennent de l'IA. Le backend doit vérifier qu'elles respectent le format #RRGGBB avant de les enregistrer (spécification §7.3). Django échappe de toute façon les valeurs. {% endcomment %} {% load l10n %} {# l10n/unlocalize : en français, Django écrirait 0,9 au lieu de 0.9, que le SVG ne comprend pas. #} {# acc = l'accessoire forcé s'il est donné, sinon celui de l'apparence (firstof ne plante pas si l'un manque). #} {% firstof accessoire apparence.accessoire "aucun" as acc %} {% with pelage=apparence.pelage|default:"#D9A066" rayures=apparence.rayures|default:"#9C6A33" opacite=apparence.rayures_opacite|default_if_none:1 yeux=apparence.yeux|default:"#7CC4A6" museau=apparence.museau|default:"#FBE9D0" %} {% endwith %}
